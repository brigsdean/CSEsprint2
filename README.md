# CSEsprint2# Overview

As a software engineer looking to strengthen my skills in object-oriented programming and Java development, I created a console-based Expense Tracker application. 

This software allows users to easily add new expenses with descriptions, amounts, and categories, view all recorded expenses, see spending broken down by category, and generate monthly summary reports. The program is built entirely in Java and demonstrates key concepts such as classes and objects, encapsulation, ArrayLists, Java Streams, and user input handling through the console.

My purpose for writing this software was to gain hands-on experience with Java syntax, working with date handling using the `java.time` package, and building a fully functional small-scale application from scratch. It helped me improve my ability to design clean, organized code and manage data effectively.
